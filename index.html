Friday Calendar Helper

Friday Calendar Helper is a private, self-hosted tool for one household. It reads and manages events on a single personal Google Calendar so a home-planning assistant can help with scheduling.

It is not a public product. There are no other users, no accounts to create, and nothing to download.

  • Runs on private hardware owned by the developer.
  • Uses Google Calendar data only for the signed-in owner's own calendar.
  • Does not sell, share, or advertise using any data.
