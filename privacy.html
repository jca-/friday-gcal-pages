Privacy Policy

Friday Calendar Helper. Last updated: November 2026.

What this is

Friday Calendar Helper is a personal, self-hosted tool used by a single person to read and manage their own Google Calendar. It is not offered to the public.

Data accessed

With the owner's consent, the app accesses Google Calendar event data (titles, times, locations, descriptions) on the owner's own calendars, using the Google Calendar API scope.

How data is used

Calendar data is used only to display, search, and schedule events for the owner. It is not used for advertising, profiling, or any other purpose.

Storage and security

OAuth tokens and any cached data stay on private hardware controlled by the owner. Data is not uploaded to third-party services other than Google's own API.

Sharing

No data is sold, rented, or shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data is kept only as long as needed to operate the tool. The owner can revoke access at any time at myaccount.google.com/permissions, and can delete stored tokens from the host.

Contact

Questions: use the contact email listed on the Google Cloud OAuth consent screen for this app.
